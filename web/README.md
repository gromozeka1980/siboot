# Trust & Betrayal: The Legacy of Siboot — веб-ремейк

Точная (1:1) веб-версия DOS-варианта игры Криса Крофорда (1987). Логика перенесена построчно
из машинного кода `SIBOOT.EXE`/`SIBOOT.OVR` (реконструкция в `../_ref/dos_src/*.pas`), экран
640×480×16 рисуется так же, как в DOS (BGI-примитивы, шрифт RMN6_13, палитры из файлов игры).

## Запуск

```bash
python tools/extract.py ../trust-and-betrayal-the-legacy-of-siboot
```
```bash
python -m http.server 8766
```
Затем открыть http://localhost:8766/ . Сборки нет — чистые ES-модули.

`extract.py` конвертирует файлы оригинальной игры (картинки, шрифты, тексты, таблицу связей)
в `assets/`. Сами ресурсы игры в код не зашиты.

Параметры адреса:
- `?seed=dos` — генератор случайных чисел стартует с 0, как в DOS (там сид никогда не
  задавался): партия идёт ход в ход как в оригинале. Так ремейк сверяется с эмулятором.
- `?seed=12345` — фиксированный сид.

## Библиотека: новелла и правила (первая современная добавка)

```bash
pip install pymupdf striprtf
```
```bash
python tools/fetch_library.py
```
Скрипт скачивает тексты с сайта автора и собирает `assets/library/`:
- новелла — расширенная авторская версия со страницы https://www.siboot-org.erasmatazz.com/novel.html
  (оригинальной новеллы из коробки 1987 года в сети нет): 6 частей, 60 глав, иллюстрации;
- правила — `Rules.rtf` из архива исходников, который выложил Крофорд
  (https://www.erasmatazz.com/library/source-code/), словарь языка eeyal показан с иконками игры.

Где открывается: крупные кнопки на экране опций (под предупреждением «без чтения
бессмысленно»), кнопки в углу во время игры, меню **Library** в меню-баре, клавиша **F1**.
Пока книга открыта, игра стоит. Место чтения и размер шрифта запоминаются.
Код: `src/modern/library.js`, `library.css`. Эталонная версия без добавок — `../classic/`.

## Архитектура

```
src/
  engine/        логика, без отрисовки (можно подключить другой интерфейс)
    state.js       всё состояние игры = глобальные переменные оригинала (JSON-сериализуемо)
    constants.js   номера слов-иконок, позиции в предложении, время суток
    game.js        главный модуль: исполнение предложений, ход времени, диалоги, история
    words.js       NewWordSet: какие иконки можно выбрать следующими (34 фильтра)
    ai.js          ИИ персонажей (PlanMyMove)
    combat.js      ночной бой аур
    events.js      случайные истории: выбор, разбор, интерпретатор команд, экран
    rng.js         генератор Turbo Pascal
  data/
    characters.js  персонажи, характеры, стартовые отношения, параметры историй — правьте здесь
  ui/            DOS-интерфейс
    qd.js          эмуляция QuickDraw поверх BGI (включённые края прямоугольников, узоры, XOR)
    draw.js        процедуры Globals: повествование, предложения, часы, лица, график чувств
    controller.js  главный цикл ввода (TakeInput)
    menus.js, dialogs.js  меню из SIBOOT.MNU и диалоги *.DIA
    screens.js     «All Characters», «Recall Today», досье, About
    title.js       логотип и экран опций
    font.js        растровые шрифты .@
  platform/      кадровый буфер 16 цветов, ввод, загрузка ресурсов
```

Движок общается с интерфейсом через объект `g.ui` (см. `docs/ENGINE_API.md`). Чтобы
осовременить игру, достаточно написать другую реализацию `ui` — логика не меняется.
