# Руководство по стилю: русский перевод «Trust & Betrayal: The Legacy of Siboot»

Для переводчиков 44 случайных событий (`assets/i18n/ru/stories/storyN.json`) и всех, кто правит русские файлы.
Термины и имена — только из [GLOSSARY.ru.md](GLOSSARY.ru.md); краткие вводные по историям — [STORY_NOTES.ru.md](STORY_NOTES.ru.md).
Проверка: `node docs/i18n/check.mjs` (из каталога `web/`) — должно вывести `OK`.

## 1. Тон

- Рассказчик Кроуфорда — **сухой, остроумный, слегка книжный**. Длинные периоды, точные слова, ирония без
  подмигивания. Не упрощайте и не «осовременивайте»: никакого сленга в авторской речи, никаких «окей» и «круто».
  Пример интонации: «Кормить разные расы так, чтобы всем угодить, за сто с лишним лет так и не научились».
- Время повествования — **настоящее**, как в оригинале («Ты входишь…», «Кендра смеётся»). Удобный побочный
  эффект: в настоящем времени у глаголов нет рода.
- Юмор держится на контрасте высокого и бытового (Пастырь и столовая, мистика и жуки). Сохраняйте оба регистра.
- Кроуфордовские «вторжения» в игру (истории 15–18, 37–42) — нарочито шутовские: там можно разговорный язык,
  восклицания, капслок, как в оригинале.
- Капслок-акценты оригинала (DO, CLEAR, FEELING) передаём капслоком: «ТЫ И ПРАВДА ужасно выглядишь».

## 2. «Ты» — это Ветвел, и она женщина

- Игрок — всегда Ветвел (персонаж 1), **женщина**. Вся речь во втором лице — в женском роде:
  «ты вошла», «ты уверена», «ты одна», «сама виновата». Род игрока пишите **прямо**; токен `{P:м|ж}` допустим,
  но не нужен.
- Обращение к ней в третьем лице (история 35 и т. п.) — тоже женский род.
- Если в оригинале «you» — это игрок-человек за компьютером (Крис: «And you, player…»), всё равно
  используем женский род — Ветвел и есть игрок.

## 3. «Ты» и «вы»

| Кто → кому | Форма | Почему |
|-----------|-------|--------|
| Рассказчик → игрок | **ты** | интимное второе лицо, как в романе |
| Аколиты между собой (в т. ч. Ветвел) | **ты** | росли вместе в колонии из 280 душ |
| Суженые, соседи, мастера (Тервел, Севар, Кормисос, Баши, Телец, Аспарух) ↔ аколиты | **ты** | Кира — тесная община; сарказм Севар передаём лексикой («Счастливых приветствий, подруга»), а не «вы» |
| Аслин → Ветвел | **вы** | мальчишка боготворит её |
| Ветвел → Аслин | **ты** | |
| Ветвел → Этанин | **вы** | «почтенная учительница» |
| Крис Кроуфорд → игрок | **ты** (фамильярно: «малыш», «детка», «дурёха») | |
| Игрок → Крис | **ты** | исключение — нарочито почтительное «Yes, Mr. Crawford, sir» → «Да, мистер Кроуфорд, сэр» (на «вы») |
| Записка Сильных Мира Сего (история 42) | **вы** | канцелярит |
| Дети, толпа → Ветвел | **ты** | |

Персонажи обращаются друг к другу **по имени**, без отчеств и титулов. «Friend» → «друг/подруга» по роду адресата.

## 4. Имена и термины

- Только формы из глоссария. **Имя — там же и так же, как в английском**: где в исходнике `{name}`, в переводе
  токен `{name.<падеж>}` (даже если история фиксирована за одним персонажем, как 7 или 12); где имя вписано
  открытым текстом (Skordokott в 2 и 43, Zubi в 8, Kendra в 26–29…), пишем русское имя из глоссария и склоняем
  сами. Число токенов `{name…}`, `{myFiance…}` и открытых имён в переводе совпадает с оригиналом.
  Местоимения при фиксированном персонаже — тоже через `{м|ж}`, если в исходнике `{he}`/`{his}`; если в исходнике
  открытое he/his — можно писать прямо (7, 12), но токены не ошибка.
- Ветвел, Вики, Зуби, Тервел, Севар, Баши, Флоффцикотт, Этанин, а также раса рипи — **не склоняются**. Склоняемые:
  Кендра, Гардбор, Локшер, Скордокотт, Аспарух, Кормисос, Телец, Аслин, Драцина, Сибут, Феслим, Крис Кроуфорд.
- Расы и языки — со строчной; Пастырь, Страна Аур, Кира, Ламина — с заглавной; аколит, аура, танага, кацин, шиал,
  иял — со строчной.
- Меры длины и времени — метрические, как в оригинале («сотни метров», «дециметры»). Исключение — шутка Криса
  «пятьдесят миль в час»: он землянин, мили оставляем.

## 5. Пунктуация и типографика

- Кавычки — **только «ёлочки», и внешние, и внутренние**: `«…Входишь к кому-нибудь в дом — говоришь «привет». Это из вежливости…»` (история 39).
  Если две закрывающие ёлочки сходятся, по возможности перестройте фразу.
  „Лапки“ не используем: рендерер превращает „“ в прямые кавычки, а в шрифте rmn6_13 их глифов нет.
  Прямая речь: `«Нет, — говорит он, — я в порядке».` В JSON ёлочки не надо экранировать; обычные `"` — надо.
- Реплика-вариант, целиком взятая в кавычки, заканчивается точкой после закрывающей ёлочки, если внутри
  нет `?`/`!`/`...`: `«Хорошо, спасибо».` — как и любой другой заголовок варианта.
- Тире — **длинное « — »** с пробелами; в прямой речи тоже. Дефис — только в словах («кто-нибудь», «8-8-8»).
- Многоточие — три точки `...` (так проще шрифту), а оригинальные `---` превращаем в тире.
- Букву **ё** пишем всегда (идёт, её, всё) — это важно для однозначности «все/всё».
- Два пробела после точки в английском исходнике не переносим: один пробел.
- Табуляции `\t` в тексте историй — абзацы; **сохраняйте их на тех же местах**.
- Запрещены символы `% ~ @ # $ ^ & = ] \` — это управляющие коды файлов историй, при сборке они вырезаются.
- Не используйте латинские буквы внутри русских слов (частая беда: латинская *c*, *o*, *a*, *p*). Скрипт проверки
  такое ловит.

## 6. Токены шаблонов

| Токен | Что даёт | Пример |
|-------|----------|--------|
| `{name}` = `{name.nom}` | имя персонажа истории, им. п. | `{name} входит.` |
| `{name.gen}` `{name.dat}` `{name.acc}` `{name.ins}` `{name.pre}` | падежи | `в дом {name.gen}`, `с {name.ins}`, `о {name.pre}` |
| `{species.<падеж>}` | раса этого персонажа (сущ. м. р.) | `у {species.gen}` |
| `{fiance.<падеж>}` | суженый этого персонажа | |
| `{myFiance.<падеж>}` | суженый игрока — всегда **Аспарух** (м) | `с {myFiance.ins}` |
| `{м\|ж}` | выбор по роду персонажа истории | `{вошёл\|вошла}`, `{он\|она}`, `{его\|её}`, `{ему\|ей}`, `{ним\|ней}`, `{сам\|сама}`, `{рад\|рада}` |
| `{P:м\|ж}` | то же по роду игрока (не нужен: игрок — женщина) | |
| `{оба\|обе}`, `{обоих\|обеих}` | «вы оба» о Ветвел и герое истории: пара смешанная → «оба», две женщины → «обе» | `Вы {оба\|обе} смотрите в пол` |

(В таблице `\|` — экранирование для Markdown; в JSON пишите просто `|`.)

Правила:

1. Английские токены `{he}` `{his}` `{him}` в исходниках — **не переносить**: заменить на `{он|она}`,
   `{его|её}`, `{ему|ей}`, `{него|неё}`, `{ним|ней}`, `{нём|ней}`.
2. Каждый глагол прошедшего времени, краткое прилагательное и причастие, относящиеся к персонажу истории,
   — через `{м|ж}`: `{name} {покраснел|покраснела}`. Проверьте мысленно фразу и с Гардбором, и с Кендрой.
3. После предлога местоимение 3-го лица с *н-*: `к {нему|ней}`, `с {ним|ней}`, `у {него|неё}`.
4. Внутри вариантов нельзя ставить `{`, `}` и `|`; вариант может быть пустым: `{|а}` → «сделал/сделала» как
   `сделал{|а}` — допустимо, но полные слова читаются лучше.
5. Имена несклоняемых героев совпадают во всех падежах, но падеж всё равно указывайте верно — так текст
   правильно заработает и со склоняемыми.
6. Если история привязана к одному персонажу (см. STORY_NOTES), токены всё равно предпочтительнее: игрок
   видит те же формы, что в остальном интерфейсе.

## 6а. Форма заголовков вариантов

- Повелительное наклонение в оригинале («Drop the matter.», «Ignore him.») → **инфинитив**: «Оставить эту тему.»,
  «Не обращать на него внимания.»
- Если текст истории обрывается на «You:» / «You are moved to:» и вариант продолжает фразу («step back…»,
  «call out…»), вариант — продолжение фразы со строчной: «отступаешь, прячешься…» / «окликнуть их…» — в той
  форме, которой требует начало фразы.
- Если оригинал уже во втором лице («You shrug your shoulders…»), оставляем второе лицо.
- Реплики — в «ёлочках», с точкой в конце (см. §5).

## 6б. Словарь, общий для историй, пояснений и значков

Одно понятие — одно слово во всех файлах: значки `words.json`, пояснения `narration.json`, истории.
сделка (принять / отклонить), предать, донести, обещание не нападать / не предавать, нарушить обещание,
извиниться (apologize) ≠ простить (forgive), мысленный поединок, счёт аур / счёт танаги. См. GLOSSARY §7–8.

## 7. Формат файла истории

`assets/i18n/ru/stories/storyN.json` — **ровно та же структура**, что `en/stories/storyN.json`:

```json
{ "text": "…", "options": [ { "title": "…", "results": ["…", "…"] }, … ] }
```

- 4 варианта (`options`), у каждого **столько же `results`, сколько в английском**, в том же порядке
  (результаты сопоставляются с командами игры по порядку; лишний или недостающий ломает историю).
- Одинаковые варианты в оригинале (история 41: четыре «Golly-gee!») остаются одинаковыми.
- Опечатки оригинала (`{name}barges`, «Asyln») молча исправляем.

## 8. Ограничения длины (после подстановки самого длинного имени — «Скордокотта»)

| Где | Лимит |
|-----|-------|
| Текст истории | без жёсткого лимита: листается страницами по 14 строк × ~50 знаков. Не раздувайте: +15 % к английскому — норма |
| Заголовок варианта (`title`) | **одна строка, ≤ 80 знаков** (рисуется в одну строку шириной экрана) |
| Результат (`results`) | ≤ ~300 знаков (≈ 8 строк по 39); обычно 1–2 фразы |
| Пояснения (narration.json) | первая строка ≤ 50 знаков, перенос по пробелу; вторая ≤ 58; итого ≤ ~105 |
| Кнопки `btn.*` | ≤ 7 знаков на строку (54 px) |
| Кнопки историй `story.*` | ≤ 5 знаков (38 px) |
| Часы | «День 12» и «12:59 ПП» — ≤ 60 px |
| Подписи лица `face.*` | ≤ 13 знаков, без точки; наречие после «выглядит» (одинаково для м и ж) |
| Пункты меню | ≤ 22 знака; буквы `key` (Alt+латинская буква) не менять |
| Диалог выхода | ≤ 30 знаков на строку |
| Подписи значков `words.json` | ≤ 3 строки, ≤ 6 узких букв в строке (~31 px шрифтом 8 px; ж ш щ ы ю м ф и дефис шире) |
| Досье | ≤ ~1000 знаков вместе с фразами о симпатиях |

## 9. Мелочи

- Числа в тексте — словами, как в оригинале («сорока трёх лет»); счета аур — цифрами через дефис.
- Междометия: «Oh, no!» → «О нет!», «Sheesh!» → «Ну и ну!», «Golly-gee! / Garsh-darn!» → «Ух ты ж! / Ёлки-палки!».
- Ругательства мягкие, как в оригинале: hell → чёрт/к чёрту, damn → чёрт, jerk → придурок, turkey → индюк.
- «Sucker» → «простофиля»; «kid» (Крис) → «малыш»; «baby» → «детка».
