# Вводные по случайным событиям 1–44

«Кто» — персонаж, подставляемый в `{name}` (по `STORY_PARM` в `src/data/characters.js`). **Любой** — может быть
любой из шести аколитов обоих полов: все согласования через `{м|ж}`. Если кто-то фиксирован, род известен,
но токены имени всё равно предпочтительнее. «Недостижима» — в обычной игре история не выпадает (флаг блокировки),
переводим всё равно. «Выключена» — включается командами других историй. `\|` в таблице — экранирование Markdown,
в JSON пишите `|`. Термины — из [GLOSSARY.ru.md](GLOSSARY.ru.md), тон и лимиты — из [STYLE.ru.md](STYLE.ru.md).
