# Глоссарий EN → RU («Доверие и предательство: Наследие Сибута»)

Единственный источник истины для всех переводчиков. Нужен новый термин? Добавьте его сюда **до того**, как использовать.
Падежные формы персонажей, их рас и суженых лежат в `assets/i18n/ru/grammar.json`; в текстах они
подставляются токенами (`{name.gen}` и т. п.), вручную их не пишите.

Сокращения: *нескл.* — не склоняется; *м/ж* — род.
