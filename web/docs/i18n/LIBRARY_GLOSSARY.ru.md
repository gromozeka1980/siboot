# Глоссарий Библиотеки (роман «The Legacy of Siboot» + правила игры) EN → RU

Для 6 переводчиков романа (`assets/library/novel.json`) и переводчика правил (`manual.json`).
Термины игры уже закреплены в [GLOSSARY.ru.md](GLOSSARY.ru.md) и [STYLE.ru.md](STYLE.ru.md): если что-то есть там, берём оттуда.
Этот файл дополняет их и решает спорное **заранее**. Одно понятие — одно слово во всех главах. Нашли имя или термин,
которого здесь нет? Образуйте его по §1 и **отметьте в конце своего файла** (список «новые имена»), чтобы их свели в одно.

**Техника (проверяет `python tools/library_i18n.py check ru`):** число и порядок блоков те же; блоки `img` не трогать;
в каждом `p` та же **последовательность HTML-тегов** (`<em>`…`</em>`), даже если теги разорваны переносом строки
(`<em>So </em> <em>you’ll…</em>`): текст внутри переводим, теги не сливаем и не удаляем. `&amp;` — сущность, можно
заменить на «и». В словаре ияла (`dict`) — те же 76 строк в том же порядке. Пустые заголовки интерлюдий (`"title": ""`)
оставляем пустыми. Опечатки оригинала (Chapay, formard, Taryan, a interpreter) и мусорные символы правил
(`Ñ` = тире, `Ê` — удалить) молча исправляем.

## 1. Транслитерация и склонение

Имена **транскрибируем по написанию** (как в игре: Vetvel → Ветвел, Gardbore → Гардбор, Bashee → Баши), не подбираем
«знакомые» русские аналоги. Правила:

| Буквы | RU | Пример |
|-------|----|--------|
| ee, ea / oo | и / у | Neef → Ниф, Heen → Хин; Siboot → Сибут, Koopie → Купи |
| ay / ey | ай / ей | Tayran → тайран, Chaypay → Чейпей |
| y между согласными; конечные -y, -ie, -ee | и | Feslym → Феслим; Timy → Тими, Stellee → Стелли |
| y перед гласной в начале слова и после гласной | й | Yelfim → Йелфим |
| aw | оу | Thawn → Тоун |
| начальное e | э | Eilen → Эйлен, Escobar → Эскобар |
| j / ch / sh / th | дж / ч / ш / т | Jopin → Джопин; Cholin → Чолин; Shaleen → Шалин; Thid → Тид |
| h / w / x | х / в / кс | Harpu → Харпу; Wiki → Вики; Gilanox → Гиланокс |
| ts, tz | ц | katsin → кацин, Hortz → Хорц |
| c, ck, k | к (перед e/i/y — с) | Sufupican → Суфупикан, Marstic → Марстик |
| g, ge, gi | г, ге, ги (всегда твёрдое г) | Genubi → Генуби, Gillespin → Гиллеспин |
| l | **л, никогда ль** | Vetvel → Ветвел, Flanell → Фланелл |
| двойные согласные | сохраняем | Skordokott, Lariltoff → Ларилтофф, Camiggdo → Камиггдо |
| немое конечное -e | отбрасываем | Mortle → Мортл, Tarkle → Таркл, Forseen → Форсин |

**Склонение** (по нормам русского языка; в таблицах указано, если нет):
- мужские на согласный и на -ей/-ай — **склоняются**: Сибут, Сибута; Чейпей, Чейпея; Каик, Каика;
- мужские на -о, -и, -у, -е — не склоняются: Купи, Генуби, Харпу, Менсо, Футло, Тими;
- женские на -а — склоняются: Ника, Текула, Промтилла, Кендра;
- женские на согласный и на -о, -и — **не склоняются**: Суфупикан, Шалин, Рево, Бити, Камиггдо, Троко, Нафимко;
- род глагола и прилагательного — по полу героя («Рево сказала», «Бити была»).

### Расы
Со строчной, как в GLOSSARY §2. В романе их **четыре**: джомкар, рипи, класт, тайран (мн. джомкары, рипи, класты, тайраны;
прил. джомкарский, рипийский, кластский, тайранский; языки — «по-кластски», «на тайранском», «перешёл на рипийский»).
«Ripi eyes» → «рипийские глаза». Kiran → **киранец / киранка / киранцы, киранский**; Laminan → **ламинец / ламинцы,
ламинский**. «You are Kiran» → «Вы — киранцы». Женских форм рас не образуем («Рево — класт»).

## 6. Стиль романа

**Голос.** Кроуфорд пишет просто, ясно, с суховатой иронией; фразы короткие, лексика нейтральная, без архаики и сленга.
Ирония — в точном слове и в контрасте высокого с бытовым (пророк и туалет, проповедь и насосы). Не украшайте и не
«олитературивайте». Прошедшее время повествования сохраняем; глава 5.11 — **настоящее время и второе лицо** («Ты стоишь…»),
пол героя «ты» не назван: строим фразы без рода, а если без него никак — женский (как у игрока-Ветвел).
Детская речь, бранные реплики и восклицания — разговорные, но мягкие (hell → чёрт, bitch → стерва, son-of-a-bitch → сукин сын,
damn → чёртов). Капслок оригинала («YEEP!», «KINST!!!», «EVERYTHING») сохраняем: «ЙИП!», «КИНСТ!!!».

**Ты / вы.**
- По умолчанию все колонисты на **ты** (крошечная община): Сибут, Рево, Чейпей, Бити между собой; сверстники, аколиты, дети.
- **Вы** — когда в оригинале есть почтение (sir, ma'am, «Siboot II», «Dear Siboot III», «Doctor»): Артигул, Сампул, Ника, Ниф,
  Суфупикан-ученица → Рево/Сибуту III; Ларилтофф, Троко, Харпу, Купи и другие ученики → учителям и Сибуту; колонисты → губернатору Граду.
  Старший отвечает на **ты** («my dear» → «моя дорогая»). Рево и Артигул — взаимно на **вы**.
- Дети → родители: **ты** (Камиггдо и Феслим тоже). Доктор Йелфим → родителям Скордокотта: **вы**.
- К толпе и в радиопроповедях — **вы** (мн.). Вселенная → Сибут: **ты**.
- ma'am → «госпожа»; sir → опускаем, вежливость держит «вы» («Yes, sir» техника → «Слушаюсь»).

**Диалог — кавычками, не тире.** Абзацы оригинала часто содержат реплики разных людей подряд; тире такое не вынесет.
Поэтому реплика в «ёлочках», слова автора по STYLE §5: «Нет, — говорит он, — я в порядке». / «Где Чейпей?» — спросил Сибут.
Реплики разных героев в одном абзаце так и остаются подряд: «Ты здесь?» «Да».
Если после реплики идёт не глагол речи, а действие — тоже тире: «Молодчина!» — Сибут хлопнул его по плечу.
Если действие — отдельная фраза, тире нет, фраза с прописной: «Я? Учительницей?» Глаза Суфупикан округлились.
- **Оборванная реплика.** Перебили, оборвали на полуслове (в оригинале `—”`) → пробел, тире, кавычка: «Они бы —».
  Замялся, не договорил (в оригинале `…”`) → многоточие: «Я не знаю…». Выбор — по оригиналу, не по вкусу.
- **Речь в несколько абзацев** (проповеди, длинные монологи): каждый абзац открывается «ёлочкой», закрывается
  только последний — как в оригинале. Абзац, начатый внутренней цитатой, всё равно открывается «: «„Ходули“, …
- **Мысли в `<em>`** — без кавычек, как в оригинале, но слова автора отбиваются тире, как в прямой речи:
  `<em>До чего же люди мелочны,</em> — думала она.`; если мысль продолжается новой фразой —
  `<em>…,</em> — подумал он. — <em>Ну и ладно.</em>`. Мысли, которые в оригинале в кавычках (4.2), — в «ёлочках».

**Фразы на ияле** (курсив, например `<em>Troko greet Lariltoff good most.</em>`) — «телеграфом», порядок слов оригинала:
имена в именительном, слова со значками — подписями значков (привет, прошу, спасибо, сообщить, спросить, чувство, гнев…),
остальные глаголы — инфинитивом, оценки наречиями: good → хорошо, powerful → сильно, most → очень-очень, much → очень,
least / negative → не-: «Троко привет Ларилтофф хорошо очень-очень.», «Купи привет Скордокотт сильно не-очень.»,
«Скордокотт любить Зуби.», «Скордокотт… мокрый.» Английские связки (that) в скобках → «(что)»; без скобок — «что».
Сводная шкала (закреплено при сводке): most / good-most → **очень-очень**; much → **очень**; least, negative-most →
**не-очень-очень**; negative-much → **не-очень**; одиночное negative → **не** («хорошая-штука не»). Дефис после «не-»
и внутри «очень-очень» обязателен, между словом и наречием — пробел («хорошо очень-очень», не «хорошо-очень-очень»).
Составные слова-образы оригинала через дефис: good-thing → «хорошая-вещь», good-stuff → «хорошая-штука».
express-feeling / feels toward → «чувство» / «чувство к» (подпись значка), express anger → «гнев», beg → «прошу»,
tell(s) → «сообщить», thanks → «спасибо», ask → «спросить»; прочие глаголы — инфинитивом («любить», «хотеть», «дать»).

**Типографика.** Всё из STYLE §5, кроме ограничений шрифта игры (Библиотека — обычный HTML):
- кавычки: внешние «ёлочки», **внутренние „лапки“** («Он сказал: „бомба вот-вот рванёт“»); одиночные ‘…’ оригинала → «…»;
- тире — длинное « — » с пробелами, в том числе где у Кроуфорда «—» слитно; дефис — только внутри слов;
- многоточие — символ «…», как в источнике;
- **ё всегда**; один пробел после точки; никакой латиницы внутри русских слов;
- запрещённые символы игры (`% ~ @ # $ ^ & = ] \`) здесь не опасны, но не добавляйте их.

**Числа и единицы.** Числа словами там, где словами в оригинале («двести пятьдесят шесть колонистов»); цифрами — где цифры
(«на странице 57», счёт аур «6-4-7», «8-8-8»). Время — 24-часовое: «1300» → «13:00», «the 3:00 horn» → «гудок в 15:00», «3:00
appointment» → «в 15:00». Метрические единицы оставляем; английские переводим в метрические с округлением: ten feet → три
метра, twenty yards → метров двадцать, 150 pounds (давление) → десять атмосфер. 360º → «круговой обзор». Номера Сибутов —
римскими цифрами.

**Длина.** Держитесь близко к оригиналу (проверка предупреждает при отношении длины вне 0,7–1,8).
