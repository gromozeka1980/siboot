# Локализация

Английский = данные оригинальной игры без изменений (ветка кода не трогается).
Любой другой язык — папка `assets/i18n/<lang>/` с JSON-файлами. Переключение: кнопка EN/RU в правом
нижнем углу (или `?lang=ru` в адресе); выбранный язык запоминается, начатая партия продолжается
после переключения.

## Как добавить язык

1. Сгенерировать исходники для перевода из файлов игры:
   ```bash
   python tools/i18n_export.py
   ```
   Появится `assets/i18n/en/` — это **источник**, его не переводят на месте, а копируют в
   `assets/i18n/<lang>/` и переводят копию.
2. Перевести файлы (формат — ниже), держась глоссария и стайлгайда языка (`docs/i18n/`).
3. Если в языке есть символы, которых нет в шрифтах игры, добавить глифы
   (пример: `tools/cyrillic_fonts.py` для кириллицы).
4. Проверить:
   ```bash
   node tools/i18n_check.mjs <lang>
   ```
   Валидатор проверяет полноту, структуру историй, токены, запрещённые символы, помещается ли
   текст в окна игры (в пикселях настоящих шрифтов) и есть ли глифы для всех символов.
5. Добавить язык в переключатель (`src/main.js`, `switchLanguage`).

## Файлы перевода

| файл | что внутри |
|------|------------|
| `ui.json` | строки интерфейса: ключи — `EN` в `src/i18n/i18n.js`, плюс `face.1`..`face.34` (подписи лиц) |
| `grammar.json` | персонажи: род, падежные формы имени, вида, жениха/невесты; правила перечисления |
| `narration.json` | 72 сообщения окна повествования (`"1"`..`"72"`) |
| `stories/storyN.json` | 44 случайных события: `text`, 4 варианта `{title, results[]}` |
| `dossiers.json` | досье `"1"`..`"8"` и шаблоны фраз об отношениях `love."1"`..`"5"` |
| `menus.json` | меню (буквы горячих клавиш `key` не меняются: это Alt+латинская буква) |
| `dialogs.json` | тексты диалога выхода |
| `words.json` | подписи иконок языка eeyal: `"номер": ["строка1", "строка2"]` |

## Шаблоны

- `{name}`, `{name.gen}`, `{name.dat}`, `{name.acc}`, `{name.ins}`, `{name.pre}` — персонаж, о котором текст
  (в сообщениях — адресат сообщения, в историях — герой истории);
- `{species.<падеж>}`, `{fiance.<падеж>}` — его вид и жених/невеста; `{myFiance.<падеж>}` — жених/невеста игрока;
- `{вошёл|вошла}` — выбор по роду этого персонажа; `{P:вошёл|вошла}` — по роду игрока (Ветвел — женщина);
- в досье: `{list.<падеж>}` — перечень персонажей, `{pl:ед|мн}` — выбор по их числу.

Символы `% ~ @ # $ ^ & = ] \` в переводах запрещены: это служебные символы формата историй оригинала.

## Как это устроено

`src/i18n/i18n.js`: истории пересобираются в **исходный формат файла игры** с переведённым текстом,
заголовками вариантов и текстами результатов; все команды (изменение чувств, переходы) остаются
байт-в-байт, поэтому оригинальный разборщик и интерпретатор работают без изменений
(проверка: `node tools/test_i18n.mjs`). Подписи иконок рисуются поверх цвета оригинальной подписи
маленьким шрифтом RMN4_08.

## Библиотека (повесть 1987 года и правила)

Тексты «Библиотеки» переводятся отдельно, кусками, которые можно раздать нескольким переводчикам:

```bash
python tools/library_i18n.py split <lang> 5   # assets/i18n/<lang>/library/work/src_NN.json (правила + 5 кусков повести)
# переводчики копируют src_NN.json в tr_NN.json и переводят строки; число и порядок блоков не меняются
python tools/library_i18n.py check <lang>     # структура, теги <em>, картинки, непереведённые абзацы
python tools/library_i18n.py merge <lang>     # -> assets/i18n/<lang>/library/manual.json, novella.json
```

Читалка (`src/modern/library.js`) берёт книги из `assets/i18n/<lang>/library/`, а если их нет — английские.
Имена, термины и названия глав — `docs/i18n/LIBRARY_GLOSSARY.ru.md`; строки самой читалки — ключи `lib.*` в `ui.json`.
