# Состояние проекта (обновлено 2026-10-11)

Ремейк DOS-игры Trust & Betrayal: The Legacy of Siboot (Chris Crawford, 1987). Эталон — DOS-файлы
(`../trust-and-betrayal-the-legacy-of-siboot`); Mac-исходник Кроуфорда (`../_ref/src`) — только справка.

## Две версии игры (сервер: `python _dosref/serve.py 8766 web _dosref/shots_web`, из папки TB)
- `index.html` — классика 1:1 с DOS (пиксельно сверено; `?seed=dos` = режим сверки, воспроизводит баги DOS).
- `play.html` — ремейк: новый интерфейс, графика, звук, RU/EN. `?lang=ru|en`, `?seed=N`.
- `classic/` — замороженная копия ранней версии.

## Архитектура
- `src/engine/` — движок (порт DOS-Паскаля). НЕ рисует: зовёт методы `view`
  (интерфейс описан в шапке `src/ui/classic/view.js`).
- `src/ui/classic/view.js` — DOS-экраны; `src/modern/view.js` — экраны ремейка (DOM).
- `src/modern/`: `app.js` (титул, конструктор фразы, меню, сохранения 3 слота + авто, журнал, погружение),
  `view.js`, `gloss.js` (перевод фраз ияла в текст), `advisor.js` («💡 Что делать?»), `tips.js` (подсказки),
  `sound.js` (синтез: звуки + «голос ияла» по расам; фоновый гул УБРАН по просьбе), `library.js` (Библиотека).
- `docs/FIXES.md` — 16 исправленных ошибок оригинала (№14: вопрос «кто предал» — только «меня»; №15–16: недостижимые истории 44 и 27–29).
- Уровень 4 «Очень сложно» (только ремейк): как уровень 3, но выбор ауры в поединке по ожидаемой выгоде
  (`smartPick` в `engine/combat.js`). Причина: формула уровня 3 у Кроуфорда тянет ИИ играть сильнейшей аурой,
  поэтому «сложный» на деле легче лёгкого.

## Навигация (ревизия UX 2026-10)
- Одна карточка персонажа (`charCard` в app.js): строка таблицы аур / портрет собеседника / «Персонажи» (плитки) →
  ауры, обещания, известные предательства, досье, симпатии. Обещания — значки в таблице аур (отдельной карточки нет).
- Закрываемые окна: × / Esc / клик мимо (`view.modal(html, true)`); окна выбора (история, ночь) — нет.
- Меню: «Игра» + «Настройки». Телефон (портрет): одна строка шапки (Ауры·Персонажи·Журнал·Меню), часы в сцене,
  Библиотека в меню.
- Блокнот аур (`view.auraLog`, сохраняется с игрой): в таблице «?» заменяется бледным последним виденным значением
  с пометкой дня; в карточке — история по дням. Реплики рассказчика, повторяющие фразу игрока, скрыты (кроме погружения).
  Подсказки к ячейкам сделки (SLOT_HINT), журнал — все известные предательства, «Продолжить» — главная кнопка титула.
  Скрипты осмотра: `_dosref/ux_tour.mjs`, `ux_probe.mjs`, `ux_land.mjs` → `_dosref/shots_ux/`.

## Графика (`assets/remake/`, WebP; PNG-оригиналы в `../remake_art/out`)
- Портреты 7, эмоции 7×10, места (7 домов, дорога, ночь, титул; планета Ламина — голубая, не газовый гигант),
  иллюстрации повести 20, историй 44, скриншоты для правил (`shots/<lang>/`).
- Семь видов (повесть 1987): каждый из 7 персонажей — свой вид: Ветвел джомкар, Кендра класт, Гардбор фрем, Вики рипи,
  Локшер локвил, Зуби срол, Скордокотт тайран (Сибут — рипи). Других рас нет. Промпты иллюстраций (ill-*, st-*) содержат
  блок SPECIES + лист `remake_art/refs/species_sheet.png` (7 портретов) и запрет на лишних персонажей; блок WORLD уступает указаниям сцены (свет, время, размер Ламины).
  Все 64 проверены по сцене (виды, состав, действие, свет), 41 перерисована, правки — строки IMPORTANT в промптах.
- Иконки ияла — векторизованные рисунки Кроуфорда (`tools/vectorize_icons.py`), AI-иконки отвергнуты.
- Генератор: `tools/remake_art.py` (OpenAI gpt-image-2; ключ в `TB/.env`, не печатать). Задания: `remake_art/jobs.json`.
  `run <jobs|prefix*>`, `pick`, `pickall`, `review` (перерисовка отклонённого), `manifest`, `spent` (~$29.4 по оценке).
- Инструмент проверки: `remake/review.html` → «Отправить» пишет `remake_art/review.json` → `remake_art.py review`.

## Результаты бота (длинная партия, % побед Ветвел; честная доля 1/7 ≈ 14%)
- random: 0–4%. smart (v1: «бей того, кто ходит аурой, бьющей его слабейшую»): ур.1 60%, 2 64%, 3 68%.
- Уровень 4 против smart: 40% (против 67% на ур.3) — сложнее, работает.
- smart2: правила включаются флагами (env F: D защита по EV, A ночная атака по EV, R выбор деталей сделки, C лимит
  4 предложения). A/B (40 партий, длина 3, победы ур.1/2/3/4): v1 23/27/26/17; R 24/26/28/18 (победа быстрее, ~15 дней
  против 17–22); AR 21/24/28/17; ADR — много ничьих на ур.1–2 (защита по EV пассивна); C один — 3–10%: меньше сделок =
  бот ничего не знает. Вывод: торговля информацией важнее всего; v1 близок к потолку простых эвристик. По умолчанию F=R.
- Лимит предложений за визит (env OC, 100 партий, F=R): OC=12 ур.3 67/ур.4 43; OC=40 ур.3 85/ур.4 40. Уровень 4 держится
  против более сильного бота. По умолчанию OC=40. NPC боту сделок почти не предлагают: бот всё время говорит сам,
  и инициатива к NPC не переходит (это свойство движка, не ошибка).
- «Молчание» (F+=S: светская беседа каждые PE предложений, NPC сам предлагает ~6 сделок за партию): ХУЖЕ —
  ур.3 33–46/100 против 85. Принимать ли их сделки — не важно (F+=N: 47); вредит потеря времени на паузы.
- Истории (env STORY, 100 партий, ур.1/3/4): random 71/85/40, smart (пробует каждый ответ на копии состояния) 62/80/48,
  worst 72/77/34. Влияние небольшое (заметно на ур.3–4), бот выигрывает знанием аур, а не отношениями. ~17 историй
  за партию; танк (42) в 12% партий; 44 (все ауры от Аслина) не выпала ни разу, 31–36 почти не выпадают. По умолчанию smart.
- Почему истории редки: 23 выпадает только в разговоре у тебя дома (бот дома не сидит; env HOME_WAIT=1 → 94/100);
  44 и 27–29 были недостижимы из-за ошибок (FIX #15, #16; теперь 83 и ~75 из 100 при HOME_WAIT); 35 — для игры не за Ветвел;
  31–34, 36 — ждать у запертой двери + сильное чувство хозяина.
- Советчик: советует торговать чаще; при составлении предложения — чью ауру выдавать (лидера) и чью узнавать
  (правило R бота). Отключается в меню: «Советчик (кнопка 💡)», localStorage siboot.advisor.
