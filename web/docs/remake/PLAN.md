# Ремейк: план

Механика и баланс — как в оригинале (движок `src/engine/` не меняется по смыслу). Меняются
графика и интерфейс. Эталон 1:1 остаётся в `classic/` и в режиме `?seed=dos`.

## Этап 1. Отделить движок от DOS-отрисовки — ✅ сделано
Сейчас движок сам рисует экраны DOS (истории, бой, защита, победа) через `ui.qd`/`ui.plotWord`.
Вводим слой событий: `narrate(msg, who)`, `say(who, sentence)`, `story(story) → выбор`,
`defence(attacker, известные ауры) → аура`, `combat(итог)`, `victory(who)`, `mood(who, лицо)`,
`stats()`. Классический экран реализует их старым кодом (проверка: lockstep с DOS и `test_playthrough`
дают те же результаты), новый — HTML-интерфейсом.

## Этап 2. Новый интерфейс — ✅ первая версия: `play.html` (`src/modern/app.js`, `view.js`, `gloss.js`)
- сцена: фон дома + большой портрет собеседника с эмоцией, шкалы любви/доверия/страха с изменением;
- лента разговора: фраза иконками + перевод обычным языком;
- конструктор фразы: слоты + доступные иконки с подписями (режим «погружения» — без подписей);
- карта колонии, таблица «что я знаю об аурах», обещания и долги;
- истории — карточкой поверх сцены; ночь — анимированный поединок аур (SVG);
- клавиатура, мышь и тач; адаптивная вёрстка; русский/английский.

Портреты → места → эмоции → (позже) иконки. Подключение: файл в `assets/remake/...` заменяет оригинал.
