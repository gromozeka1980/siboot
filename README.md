# Trust & Betrayal: The Legacy of Siboot — web remake

A web port of Chris Crawford's 1987 game (DOS version as the reference), plus a modernised remake with redrawn art,
sound, a Russian translation and an in-game library (the 1987 rules and novella).

- `web/play.html` — the remake; `web/index.html` — the original, pixel-exact to DOS (`?seed=dos` reproduces its bugs).
- Run locally: `python _dosref/serve.py 8766 web _dosref/shots_web`, then open http://localhost:8766/play.html
- Project status and tools: `web/docs/STATUS.md`; fixed bugs of the original: `web/docs/FIXES.md`.

The original game, its texts and story content are by Chris Crawford.
